# Homebrew Tap for `syk4y`

This is the Homebrew tap for [`syk4y`](https://github.com/TaiDuc1001/syk4y-apt), a CLI for repeatable Kaggle artifact workflows.

## Install

```bash
brew install mihtriii/syk4y/syk4y
```

Homebrew 6+ asks for explicit trust for non-official taps. Installing the fully qualified formula above trusts only `syk4y`.

## Update

```bash
brew update
brew upgrade syk4y
```

The `syk4y` macOS release workflow updates `Formula/syk4y.rb` after every successful build from the source repository's `main` branch.
